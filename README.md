# 🏎️ PitLine.com

**PitLine.com** je informační web o Formuli 1 určený pro nové i zkušené fanoušky. Najdete zde přehled závodníků, výsledků, nadcházejících Grand Prix i historických dat. Cílem je jednoduchá a přehledná platforma, která Vám poskytne všechny důležité informace o F1 na jednom místě.

## 📌 Cíl projektu

- Zjednodušit přístup k informacím o Formuli 1, vytvořit moderní a přehlednou stránku pro fanoušky. Ideální pro ty, kdo chtějí rychlý přehled bez složitostí.
- Vylepšení dovedností v HTML, JS, a CSS
